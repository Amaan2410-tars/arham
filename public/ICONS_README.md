# PWA Icons

The PWA manifest requires icon files. You need to create:

1. `icon-192.png` - 192x192 pixels
2. `icon-512.png` - 512x512 pixels

## How to Create Icons

### Option 1: Online Icon Generator
1. Go to https://realfavicongenerator.net/ or https://www.pwabuilder.com/imageGenerator
2. Upload your logo or create an icon
3. Download the generated icons
4. Place them in the `public/` folder

### Option 2: Design Tool
1. Create a square icon (at least 512x512)
2. Export as PNG:
   - `icon-192.png` (192x192)
   - `icon-512.png` (512x512)
3. Place in `public/` folder

### Option 3: Quick Placeholder
For development, you can use any square image and resize it to 192x192 and 512x512.

## Icon Design Tips
- Use your brand colors (Royal Blue #2563eb)
- Keep it simple and recognizable
- Ensure it looks good at small sizes
- Use transparent background or solid color

## After Creating Icons
The icons will be automatically used by the PWA manifest. No code changes needed.
